# **Google Sheets FAQs**

## Overview

This document provides FAQs for Google Sheets. It includes separate sections for employee-facing and admin-facing questions.

## End user FAQs

**How do I create a new sheet within a Google Sheets file?**  
To create a new sheet, follow these steps:

1. Select the **\+ button** at the bottom left corner of the Google Sheets interface.  
2. Or right-click on an existing sheet tab.  
3. Select **Insert sheet**.

**Can I import data from an Excel file into Google Sheets?**  
Yes. To import data from Excel, follow these steps:

1. Open a Google Sheets file.  
2. Select the **File** menu.  
3. Select **Import**.  
4. Choose the **Upload** tab and upload your Excel file.

**How do I create formulas and perform calculations in Google Sheets?**   
You can use formulas and functions to perform calculations. Enter a formula directly into a cell using the "**\=**" sign.  
**For example**, enter **`=A1+B1`** to add the values in cells A1 and B1.

**Can I freeze rows or columns in Google Sheets?**  
Yes. To freeze rows or columns, follow these steps:

1. Select the row or column you want to freeze.  
2. Select the **View** menu.  
3. Choose **Freeze**.  
4. Select either **1 row** or **1 column**.

**How do I protect cells or sheets in Google Sheets from being edited by others?**  
To protect cells or sheets, follow these steps:

1. Select the **Data** menu.  
2. Select **Protect sheets and ranges**.  
3. Specify the range or sheet you want to protect.  
4. Set the access permissions for users.

**How do I create charts and graphs in Google Sheets?**  
To create charts or graphs, follow these steps:

1. Select the data you want to include in the chart.  
2. Select the **Insert** menu.  
3. Choose the chart type, such as bar, line, pie, or scatter plot.  
4. Google Sheets generates the chart based on your selection.

**Can I collaborate with others on a Google Sheets file?**  
Yes. To share and collaborate, follow these steps:

1. Select the **Share** button in the top-right corner.  
2. Enter the email addresses of the collaborators.  
3. Choose their access level (view, comment, or edit).

**How do I filter and sort data in Google Sheets?**  
To filter or sort data, follow these steps:

1. Select the range you want to work with.  
2. Select the **Data** menu.  
3. Choose **Filter views** to apply filters.  
4. Or choose **Sort range** to sort data by selected columns.

**Is it possible to link cells between different Google Sheets files?**  
Yes. Use the **`=IMPORTRANGE`** function to import data from one Google Sheet to another.  
Specify the source sheet’s URL and the range to import.

**Can I create data validation rules in Google Sheets?**  
Yes. To create data validation rules, follow these steps:

1. Select the **Data** menu.

2. Select **Data validation**.  
3. Set rules to control the type and range of data that can be entered into specific cells.
