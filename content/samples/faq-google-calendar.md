# **Google Calendar FAQs**

## Overview

This document provides FAQs for Google Calendar. It includes separate sections for employee-facing and admin-facing questions.

## End user FAQs

**How do I create an event in Google Calendar?**  
To create an event, follow these steps:

1. Open Google Calendar.  
2. Select the **\+ Create** button or select a time slot in the calendar grid.  
3. Enter the event title, date, time, location, and any other details.  
4. Select **Save** to create the event.

**Can I invite others to my events in Google Calendar?**  
Yes. To invite others, follow these steps:

1. Create or edit an event in Google Calendar.  
2. Go to the **Add guests** section.  
3. Enter the email addresses of the people you want to invite.  
4. Guests receive an email invitation and can RSVP to the event.

**How do I share my Google Calendar with others?**  
To share your calendar, follow these steps:

1. Open Google Calendar.  
2. Go to **Settings** and select the calendar you want to share.  
3. Choose **Access permissions** or **Share with specific people**.  
4. Enter the email addresses of the people you want to share with.  
5. Choose their access level (see only free/busy, see all event details, or make changes).

**Can I create multiple calendars in Google Calendar?**  
Yes. To create multiple calendars, follow these steps:

1. Open Google Calendar.  
2. In the left sidebar, select **\+ Create new calendar**.  
3. Enter the calendar details.  
4. Save and customize its events, settings, and sharing permissions.

**How do I set reminders for events in Google Calendar?**  
To set reminders for events, follow these steps:

1. Create or edit an event in Google Calendar.  
2. Scroll to the **Notifications** section.  
3. Select the reminder option (email, popup, or SMS).  
4. Save your changes.

**Is it possible to create recurring events in Google Calendar?**  
Yes. To create recurring events, follow these steps:

1. Create or edit an event in Google Calendar.  
2. Select the **Does not repeat** option.  
3. Select a recurrence pattern (daily, weekly, monthly).  
4. Set the frequency and end date as needed.

**How do I view other people’s calendars in Google Calendar?**  
To view another person’s calendar, follow these steps:

1. Open Google Calendar.  
2. In the left sidebar, select **\+ Add** next to "Add a friend's calendar"  
3. Enter the person’s email address.  
4. Their calendar events appear alongside yours if they have shared access.

**Can I sync Google Calendar with other calendar applications?**  
Yes. To sync Google Calendar, follow these steps:

1. Open Google Calendar.  
2. Export or subscribe to the calendar’s URL (iCal format).  
3. Import or sync using another calendar application or supported integration.

**How do I change the time zone in Google Calendar?**  
To change your time zone, follow these steps:

1. Open Google Calendar.  
2. Go to **Settings**.  
3. Scroll down to the **Time zone** section.  
4. Select **Primary time zone** and choose your preferred time zone.  
5. Or select **Automatic** to let Google Calendar detect your current time zone.

**Is it possible to add attachments to events in Google Calendar?**  
Yes. To add attachments, follow these steps:

1. Create or edit a calendar event.  
2. Select the option to add a file from Google Drive.  
3. Share file access with event participants as prompted.
