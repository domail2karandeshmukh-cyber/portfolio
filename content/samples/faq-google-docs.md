# **Google Docs FAQs**

## Overview

This document provides FAQs for Google Docs. It includes separate sections for employee-facing and admin-facing questions.

## End user FAQs

**How do I share a Google Docs file with others?**  
To share a Google Docs file, follow these steps:

1. Select the **Share** button (top-right).

   ![][image1]

2. Enter the **email** **addresses** of the people you want to share with.  
3. Choose their access level (**viewer**, **commenter**, or **editor**).  
4. Select **Send**.

   ![][image2]

**Can I work on Google Docs offline?**  
Yes. To work on Google Docs offline, follow these steps:

1. Open **Google** **Drive** in Chrome.  
2. Select the **Settings (gear)** icon in the top-right corner. 

   ![][image3]

3. Select **Settings**.

   ![][image4]

4. Scroll down and check the **Offline** box to enable offline access.

   ![][image5]

5. Create, edit, and view your documents without an internet connection.

**Is it possible to convert a Google Docs file to a Microsoft Word document?**  
Yes. To convert a Google Docs file to Word format, follow these steps:

1. Open the **document** in Google Docs.  
2. Select the **File** menu.  
3. Select **Download**.  
4. Choose the Word format (.docx or .doc).  
   

**How do I track changes and collaborate with others on a Google Docs file?**  
To track changes and collaborate, follow these steps:

1. Open the document in Google Docs.  
2. Select **Share** and invite collaborators.  
3. Choose their access level.  
4. Add comments and suggestions as needed.

**Can I add custom fonts to Google Docs?**  
Yes. To add custom fonts, follow these steps:

1. Open a document in Google Docs.  
2. Go to the font dropdown in the toolbar.  
3. Select **More Fonts**.  
4. Select additional fonts to use in your document.

**How do I insert images or graphics into a Google Docs document?**  
To insert images or graphics, follow these steps:

1. Open a document in Google Docs.  
2. Select the **Insert** menu.  
3. Select **Image**.  
4. Upload from your computer, Google Drive, or search the web.

**Is there a maximum file size limit for Google Docs?**  
Yes. Google Docs supports files up to 1.02 million characters  
Files with many images, tables, or formatting may reach the limit sooner.

**How do I format text, paragraphs, and headings in Google Docs?**  
To format content in Google Docs, follow these steps:

1. Open a document in Google Docs.  
2. Use the toolbar for font styles and sizes.  
3. Apply bold, italics, underline, alignment, bullet points, numbering, and heading styles as needed.

**Can I add footnotes, page numbers, and a table of contents in Google Docs?**  
Yes. To add these elements, follow these steps:

1. Open a document in Google Docs.  
2. Select the **Insert** menu.  
3. Choose **Footnote**, **Page number**, or **Table of contents**.

**How do I access revision history in Google Docs?**  
To access revision history, follow these steps:

1. Open a document in Google Docs.  
2. Select the **File** menu.  
3. Select **Version history**.  
4. View or restore earlier versions of the document.
