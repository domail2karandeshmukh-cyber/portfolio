## Keycloak refuses the code {#code-refused}

**Cause.** The code is from an earlier period, or the phone's clock is wrong.
A code is valid for one period of the realm's OTP policy, 30 seconds by default.
With the default look around window of 1, Keycloak also accepts the code of the period before and the period after, and refuses a code from two periods back.

<Screenshot src="/img/keycloak/10-wrong-code.png" alt="Mobile Authenticator Setup after a refused code. The message Invalid authenticator code. is outlined in green, and the key is covered." caption="Keycloak's message for a refused code." />

**Fix.**

1. Ask the user to type the code that the app shows now, before its timer runs out.
2. If every code fails, ask the user to set the phone's date and time to update automatically.
   An authenticator computes each code from the time, so a phone that's a minute off produces codes Keycloak refuses.
3. If many users' codes fail, check the server's clock before you widen the look around window in the [OTP policy](../reference/otp-policy.mdx#settings).
   A wider window accepts older codes, for everyone.

## The user lost the phone {#phone-lost}

**Cause.** The authenticator went with the phone, and Keycloak keeps no copy within the user's reach.

**Fix.**

<ConfirmIdentity />

Sign the user out, require a new authenticator and delete the lost phone's OTP credential, as [Reset a user's OTP credential](../how-to/reset-otp.mdx) describes.

## Keycloak doesn't ask for a code {#no-code-asked}

**Cause.** An administrator deleted the user's OTP credential, and nothing asked the user to set up a new one.
Keycloak's default sign-in flow asks for a second factor only from a user who has one configured.

<Screenshot src="/img/keycloak/06-password-only.png" alt="The Personal info page of the account console, open after a sign-in with the password alone" caption="Signed in with the password alone." />

**Fix.** On the user's **Details** tab, in **Required user actions**, select **Configure OTP**, and then select **Save**.
At the next sign-in, Keycloak asks the user to set up an authenticator before they get in.
