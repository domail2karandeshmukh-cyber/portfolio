# OTP Policy Settings

<PageFacts />

A realm's OTP policy decides what a one-time password (OTP) looks like in it: how long a code lasts, how many digits it has, and how much clock difference Keycloak forgives.
In the admin console, it's under **Authentication** > **Policies** > **OTP Policy**.

<Screenshot src="/img/keycloak/13-otp-policy.png" alt="The OTP Policy tab of a new realm, with its default values" caption="A new realm's OTP policy in Keycloak 26.8.2." />

## Settings {#settings}

The defaults are those of a new realm in Keycloak 26.8.2.

<div className="tbl tbl--spec">

| Setting | Default | What it decides |
|---|---|---|
| **OTP type** | Time based | A time-based code changes every period. A counter-based code changes each time the user asks the app for one. |
| **OTP hash algorithm** | **SHA1** | The algorithm the app and Keycloak use to compute a code. |
| **Number of digits** | 6 | The length of a code: 6 or 8. |
| **Look around window** | 1 | How many periods before and after the current one Keycloak also accepts. |
| **OTP Token period** | 30 seconds | How long a time-based code lasts. |
| **Supported applications** | FreeOTP, Google Authenticator, Microsoft Authenticator | The apps that **Mobile Authenticator Setup** lists for users to install. |
| **Reusable token** | Off | Whether a code that has signed someone in works again before it expires. |

</div>

## Admin REST API Fields {#rest-fields}

Each setting is a field of the realm representation, at `GET /admin/realms/{realm}`.

<div className="tbl tbl--striped">

| Field | Default |
|---|---|
| `otpPolicyType` | `totp` |
| `otpPolicyAlgorithm` | `HmacSHA1` |
| `otpPolicyDigits` | `6` |
| `otpPolicyLookAheadWindow` | `1` |
| `otpPolicyPeriod` | `30` |
| `otpPolicyCodeReusable` | `false` |
| `otpPolicyInitialCounter` | `0`, used only by counter-based codes |

</div>

## Before You Change a Setting {#before-change}

A change applies only to authenticators set up after it.
Each OTP credential keeps the type, digits, period and algorithm it was set up with: after a change from 6 to 8 digits, a phone set up before the change still signed in with 6-digit codes.
To move a user to the new policy, [reset their one-time password](../how-to/reset-otp.mdx).
To move many users, [reset them with the admin REST API](../how-to/reset-otp.mdx#rest-api).
