KC1 Prediction API Reference

The KC1 API serves the project’s defect-prediction model over HTTP. Send the 21 static code metrics of one software module, and it returns whether the model flags the module as defective, with the probability and the threshold behind the decision.

FastAPI’s test client recorded every request and response on this page on 19 November 2026, against the model that the project’s own trainer produced. The test client calls the application in the same process, so the recording needed no server and no port. The trained model reproduces the model card: logistic regression with balanced class weights, a threshold of 0.50, and F1 0.500 on the 243 test modules.

At a Glance

ItemValue
Base URLhttp://127.0.0.1:8000, when you start the API with the project’s Docker Compose file. The Compose file publishes the port on this computer only.

PaginationDoesn’t apply. Each call returns one object.

Endpoints

MethodPathWhat it does
GET/Names the API and the model it serves.
GET/healthSays whether the API has loaded the model, with its name, its threshold, and the number of features it expects.
POST/predictPredicts whether one module is defective.

None of the endpoints takes a path parameter or a query parameter.

GET /health

Check that the API is up and has loaded the model, before you send predictions.

curl http://127.0.0.1:8000/health

The API answers 200 OK.

{
  "status": "ok",
  "model_loaded": true,
  "model": "Logistic balanced",
  "threshold": 0.5,
  "feature_count": 21
}
FieldTypeMeaning
statusstringok whenever the API answers.
model_loadedbooleantrue when the model loaded at startup. The API doesn’t start without a model, so it’s always true in practice.
modelstringThe name of the candidate the trainer selected.
thresholdnumberThe probability at and above which a module is called defective.
feature_countintegerThe number of metrics /predict expects: 21.

GET / returns a shorter form of the same: {"message": "Group 6 KC1 Software Defect Prediction API", "model": "Logistic balanced"}.

POST /predict

Send the metrics of one module. The API answers with one prediction.

Request Body

A JSON object with exactly these 21 fields, each a finite number. A field that is missing, a field that isn’t on the list, and a value that isn’t a number are all refused. The definitions follow the PROMISE repository’s description of KC1.

FieldMeaning
locMcCabe’s count of lines of code
v(g)McCabe’s cyclomatic complexity
ev(g)McCabe’s essential complexity
iv(g)McCabe’s design complexity
nHalstead’s total of operators and operands
vHalstead volume
lHalstead program level, about 1 divided by d
dHalstead difficulty
iHalstead intelligence content
eHalstead effort
bHalstead’s estimate of delivered bugs
tHalstead’s time estimate
lOCodeLines of code
lOCommentLines of comments
lOBlankBlank lines
locCodeAndCommentLines with both code and a comment
uniq_OpUnique operators
uniq_OpndUnique operands
total_OpTotal operators
total_OpndTotal operands
branchCountBranches in the flow graph

Three names contain parentheses: v(g), ev(g) and iv(g). The API also accepts them as v_g, ev_g and iv_g, which suit tools that don’t accept parentheses in a name. The recorded responses are the same either way.

Example

Here are the metrics of a module from the KC1 data set.

curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"loc": 25, "v(g)": 3, "ev(g)": 1, "iv(g)": 3, "n": 58, "v": 254.75, "l": 0.11, "d": 9.35, "i": 27.25, "e": 2381.95, "b": 0.08, "t": 132.33, "lOCode": 21, "lOComment": 0, "lOBlank": 2, "locCodeAndComment": 0, "uniq_Op": 11, "uniq_Opnd": 10, "total_Op": 41, "total_Opnd": 17, "branchCount": 5}'

The API answers 200 OK.

{
  "prediction": 0,
  "label": "Non-defective",
  "defect_probability": 0.3920490229417669,
  "threshold": 0.5,
  "model": "Logistic balanced"
}

Response

FieldTypeMeaning
predictioninteger1 when the model flags the module as defective, 0 when it doesn’t.
labelstringDefective or Non-defective, the same decision in words.
defect_probabilitynumberThe model’s probability that the module is defective, from 0 to 1. It is null only for a model without probabilities, which the selected model isn’t.
thresholdnumberThe probability at and above which prediction is 1.
modelstringThe model that made the prediction.

A flagged module, recorded the same way, comes back as {"prediction": 1, "label": "Defective", "defect_probability": 0.6756835241062081, "threshold": 0.5, "model": "Logistic balanced"}.

Errors

StatusWhenBody
422 Unprocessable ContentA field is missing, a field isn’t one of the 21, a value isn’t a number or isn’t finite, or the body isn’t a JSON object.detail: one entry for each problem, with its type, its location loc, a message msg and the input that caused it.
404 Not FoundThe path doesn’t exist, such as /predictions.{"detail": "Not Found"}
405 Method Not AllowedThe path exists but takes another method, such as GET /predict.{"detail": "Method Not Allowed"}

A request that sends only loc gets one entry for each of the 20 missing fields. Here is the first one.

{
  "type": "missing",
  "loc": ["body", "v(g)"],
  "msg": "Field required",
  "input": {"loc": 123}
}

Code Examples

Here is the same request in Python, with the requests library.

import requests

metrics = {
    "loc": 25, "v(g)": 3, "ev(g)": 1, "iv(g)": 3, "n": 58, "v": 254.75, "l": 0.11,
    "d": 9.35, "i": 27.25, "e": 2381.95, "b": 0.08, "t": 132.33, "lOCode": 21,
    "lOComment": 0, "lOBlank": 2, "locCodeAndComment": 0, "uniq_Op": 11,
    "uniq_Opnd": 10, "total_Op": 41, "total_Opnd": 17, "branchCount": 5,
}
response = requests.post("http://127.0.0.1:8000/predict", json=metrics, timeout=10)
response.raise_for_status()
result = response.json()
print(result["label"], round(result["defect_probability"], 3))

Run against the API, with the test client in place of the network, it prints Non-defective 0.392. The same request in JavaScript uses fetch, in a module or an async function.

const response = await fetch("http://127.0.0.1:8000/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(metrics),   // the same 21 fields
});
if (!response.ok) throw new Error(`KC1 API: ${response.status}`);
const { label, defect_probability } = await response.json();
