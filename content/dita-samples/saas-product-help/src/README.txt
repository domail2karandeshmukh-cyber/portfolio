To publish it with DITA Open Toolkit 4:

  dita --input=saas-product-help.ditamap --format=html5 --output=out/html5
  dita --input=saas-product-help.ditamap --format=pdf --output=out/pdf

To bring it into MadCap Flare: Project > Import > DITA Document Set, and choose the map.
