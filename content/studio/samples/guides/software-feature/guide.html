Schedule a report for automatic delivery

Document ID TR-BR-007-G · Version 1.0

Send a report to the people who need it every week or every month, without opening Beacon Reports on the day. Fictional sample written for this portfolio: the application is invented.

Before you start

  • You can open the report you want to send.
  • You have the recipients' email addresses.

Steps

  1. Open the report, and then select Schedule

    The schedule dialog opens.

  2. Enter each recipient and press Enter

    Each address appears as a chip under the field. Recipients don't need a Beacon account.

  3. Choose how often, the day, and the time

    The time is shown in your time zone. The report uses the data available at that moment.

  4. Choose the format, and then select Preview

    PDF for a report people read, Spreadsheet for one they work with. The preview shows the subject, the attachment's name and the recipients.

  5. Select Save schedule

    The dialog closes and a message names the next delivery.

  6. Check the schedule on the Schedules tab

    Select Edit to change it or Pause to stop it without deleting it.

Check your work

A message confirms the schedule and names the next delivery, and the report's Schedules tab lists it.
