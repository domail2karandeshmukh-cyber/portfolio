Step Guide Studio

Build a numbered procedure from screenshots: a title and an instruction for each step, a marked-up picture, the prerequisites, the warnings, and the check that tells the reader they're done. Export it as Markdown, HTML or PDF.

The headings the tool writes, such as Before you start and Steps, follow this language. Your own words are never translated.

    Mark up the picture

    Pictures are kept with the guide in this browser and in the project file. Each picture can be marked up with the same tools as the Screenshot Studio, including permanent redaction. The PDF uses a standard font, so it shows Latin-script languages only. Shortcuts: Ctrl+Z undo, Ctrl+Shift+Z redo, Ctrl+S save the project.
