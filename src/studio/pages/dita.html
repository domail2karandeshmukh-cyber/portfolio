Into other authoring tools

The project uses formats that professional tools document as importable. MadCap Flare imports a DITA document set (Project > Import > DITA Document Set), Markdown files, and HTML. The workbench and the step guides export all three.

What isn't tested: I don't have MadCap Flare, so importing these files into Flare itself hasn't been tried. The files are tested against the DITA standard and with DITA Open Toolkit, not against Flare.
